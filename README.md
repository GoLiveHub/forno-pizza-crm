# Forno Pizza CRM

Калькулятор/CRM пиццерии + публичная витрина. PHP 8 + SQLite, без фреймворков.

## Возможности

- **Касса (POS)** — продажи, кастомизация пиццы (размер 30/40 см, тесто, убрать/добавить ингредиенты), печать чека.
- **Заказы с сайта** — приём, статусы (принято → готовится → в пути → доставлено), автоназначение курьеров.
- **KDS** — экран кухни отдельной страницей.
- **Меню и прайс** — категории, позиции, фото позиций (витрина берёт их из БД).
- **Склад** — ингредиенты, рецепты, закупки, списание по заказам, контроль минимума.
- **Клиенты** — база + чёрный список, **промокоды** (%, фикс., 2×1, по категории).
- **Отчёты** — выручка, топ позиций, часы пик, эффективность курьеров.
- **Персонал** — роли (owner/admin/manager/cashier/support/cook/courier), аудит действий.
- **Уведомления в Telegram** — о новых заказах (при заполнении токена бота).
- **Локализация** — украинский/русский переключается на лету (runtime-словарь).

## Структура

```
api/             PHP-бэкенд (авторизация, заказы, меню, склад, отчёты, Telegram)
site/            публичная витрина (index.html + js + css) — GitHub Pages
js/              фронтенд админки (app.html), модули
css/             стили админки
kds.html         экран кухни
login.html       вход
tests/           тесты (smoke — локально, с тестовыми учётками)
tools/           вспомогательные скрипты
logs/            журнал работ (CHANGELOG)
```

## Запуск локально

Требуется PHP 8+ с `pdo_sqlite` и веб-сервер (Apache/Nginx/OSPanel).

1. Скопируйте проект в корень сайта.
2. В `api/config.php` задайте свой пароль в `BOOTSTRAP_PASS` (и при желании `ORDER_SITE_KEY`, Telegram-токен).
3. Откройте `app.html` — БД `data/crm.db` и первый администратор создадутся автоматически.

```sh
# пример для PHP dev-сервера
php -S localhost:8000
# затем откройте http://localhost:8000/app.html
```

> `data/`, `uploads/`, `backup/`, `logs/diffs/` и `tests/smoke.php` не входят в репозиторий (БД содержит персональные данные и пароли).
