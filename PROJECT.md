# Forno Pizza CRM

CRM-система для піцерії: каса, замовлення, кухня, склад, клієнти, чат, акції, звіти, персонал, налаштування, аудит + публічна вітрина з оформленням і трекінгом замовлення.

## Стек

- PHP 8.x + SQLite (PDO, WAL), без композера і зовнішніх залежностей.
- Чистий JS (ES5-стиль) на фронті без фреймворків, fetch + модалки.
- Один SQLite-файл: `data/crm.db` (створюється автоматично при першому запиті).

## Структура

```

  db.php           Підключення SQLite, схема, авто-міграції, сиди, хелпери
  helpers.php      JSON, сесії, ролі, CSRF, rate limit, валідація, Telegram
  orders_core.php  Ядро: створення замовлення, промокоди, списання складу
  pos.php          Каса: меню, промокод, створення замовлення, пошук клієнта
  orders.php       Список замовлень, статуси, чат оператора
  kds.php          Кухонна стрічка (new/cooking -> done)
  menu.php         Категорії та позиції меню
  stock.php        Інгредієнти, рецепти, закупки, рухи
  clients.php      Клієнти, чорний список, нотатки
  discounts.php    Промокоди (percent/fixed/bogo, категорії, терміни, ліміти)
  chat.php         Список діалогів з клієнтами
  reports.php      Виручка, топ позицій, статуси, години пік, динаміка
  users.php        Персонал (admin)
  settings.php     Заклад, доставка, Telegram (admin)
  audit.php        Журнал дій (admin)
  order_in.php     Публічний прийом замовлень з вітрини (+ чат клієнта)

js/
  api.js           Загальний шар запитів, CSRF, сесія
  ui.js            Модалки, тости, бейджі, печать чека
  app.js           Каркас: навігація по ролях, роутер модулів

  modules/         pos, orders, menu, stock, clients, kds, chat,

```

## Ролі

| Роль        | Доступ |
|-------------|--------|
| admin       | Все (вкл. персонал, налаштування, аудит) |
| cashier     | Каса, замовлення, меню, склад, клієнти, акції, звіти, чат |
| cook        | Кухня (KDS), замовлення (тільки свої переходи), меню, склад (читання) |
| courier     | Замовлення (статуси доставки), чат |

## Логіка замовлення

- Ціни завжди з сервера (`menu_items`), кошик з клієнта — тільки `item_id`/`qty`.
- Позиції з рецептом перевіряються по складу (стоп-лист); при створенні — списання інгредієнтів.
- Скасування замовлення повертає інгредієнти на склад.
- Промокоди: відсоток / фіксована сума / 2 по ціні 1, прив'язка до категорії, мін. сума, терміни, ліміт.
- Клієнт шукається за телефоном; чорний список блокує замовлення.
- Telegram-сповіщення про нові замовлення (якщо налаштовано в settings).

## Вітрина (site/)

- Меню з категоріями, кошик, оформлення (доставка/самовивіз, оплата, промокод).
- Після замовлення — сторінка статусу та чат з оператором (polling 15 с).
- Захист: заголовок `X-Site-Key` (у `config.php` → `ORDER_SITE_KEY`), rate limit, перевірка згоди на обробку даних, анти-спам.

## Встановлення

1. Помістіть теку в docroot (наприклад `C:\OSPanel\home\pizzacrm`) і відкрийте домен `pizzarcm.local` (або поправте `APP_DOMAIN` у `api/config.php`).
2. Перший запуск сам створить `data/crm.db`, таблиці, демо-меню та адміна:
   - логін: `admin`, пароль: `admin-2026` (змініть `BOOTSTRAP_PASS` до продакшену).
3. Вітрина доступна за `…/site/`.
4. Для Telegram-сповіщень заповніть токен бота та chat_id в CRM → «Налаштування».

## Перевірка

```bash
php -l api/*.php
node --check js/**/*.js
```

Смоук-тест: підняти `php -S 127.0.0.1:8399 -t .`, виконати `tests/smoke.php` (логін адміном → замовлення через POS і сайт → чат → звіти).

## Безпека

- PDO prepared statements всюди.
- CSRF-токен у сесії для всіх POST.
- Rate limit на логін і на публічний прийом замовлень.
- Перевірка Origin для POST логіна.
- Заборона доступу до `config/db/helpers` та файлів `.db`, даних.
- CSP-заголовки, nosniff, заборона фреймінгу.

## Токени-якоря для продакшену (config.php)

- `BOOTSTRAP_PASS` — початковий пароль адміна.
- `ORDER_SITE_KEY` — секретний ключ вітрини.
- `LIQPAY_PUBLIC_KEY` / `LIQPAY_PRIVATE_KEY` — онлайн-оплата (демо-режим, поки порожньо).
- `TG_BOT_TOKEN` / `TG_CHAT_ID` — Telegram.
